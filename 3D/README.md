3d Model Files for printing Kohs Cubes


kohs-male.stl - Print 16 of these per set of cubed (color red)

kohs cube.3mf - A single full cube in 4 colors.  This is a GENERIC 3mf.  If used with a Bambu printer, use IMPORT, not OPEN.

kohs cube-bambu.3mf - A set of print plates for Bambu A1 or larger.  
   Plate 1 - AMS full color plate (slow and wasteful)
   Plate 2 - A set of 16 male quarter parts. (red)
   Plate 3 - A set of 16 female quarter parts. (white)
   Plate 4 - A set of 16 female quarter parts. (blue)
   Plate 5 - A set of 16 female quarter parts. (yellow)
   Plate 6 - A set of tray parts. (any color)
